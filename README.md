# MST using Kruskal’s Algorithm 🌐

C++ program to construct a Minimum Spanning Tree (MST) using **Kruskal’s Algorithm**.

---

## 📖 Description
- Sorts edges by weight
- Uses Union-Find (Disjoint Set Union) to avoid cycles
- Selects edges until MST is formed
- Time Complexity: O(E log E)

---

## ▶️ Compilation & Run
```bash
g++ kruskal.cpp -o kruskal
./kruskal
